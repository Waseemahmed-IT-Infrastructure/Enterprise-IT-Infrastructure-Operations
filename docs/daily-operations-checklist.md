# Daily Infrastructure Operations Checklist

Use this checklist for authorized operational reviews. Record findings in an approved internal system, not this public repository.

- [ ] Review critical monitoring alerts and device availability
- [ ] Review network interface errors and connectivity incidents
- [ ] Review Windows Server services, storage, and event logs
- [ ] Check VMware host alarms and datastore capacity
- [ ] Review physical server hardware alerts
- [ ] Check endpoint patch failures and reporting gaps
- [ ] Review backup job results and outstanding incidents
- [ ] Confirm scheduled changes and complete handover notes

## Follow-up

Record issue, impact, owner, action, verification, and next review time in the authorized ticketing system.
