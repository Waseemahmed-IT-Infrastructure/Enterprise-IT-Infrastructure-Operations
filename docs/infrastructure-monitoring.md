# Infrastructure Monitoring Review

## Network

Review device availability, interface state, errors, utilization, and relevant alerts.

## Windows Server

Review CPU, memory, disk capacity, critical service state, and recent system events.

## VMware

Review host alarms, virtual machine health, datastore capacity, and resource contention.

## Physical servers

Review hardware alerts through authorized management tools.

## Alert response

Confirm scope, correlate symptoms, follow approved remediation, verify recovery, and document the outcome.

Do not publish monitoring exports or internal dashboards.
