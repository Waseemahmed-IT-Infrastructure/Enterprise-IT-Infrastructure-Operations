# Infrastructure Change Management

## Before implementation

- [ ] Define scope, purpose, and affected services
- [ ] Assess risks, dependencies, and user impact
- [ ] Confirm approval and maintenance window
- [ ] Confirm backup and recovery readiness
- [ ] Prepare implementation and rollback instructions
- [ ] Define success criteria and communication plan

## During implementation

- Follow approved steps and record deviations.
- Stop and escalate when unexpected risks arise.

## After implementation

- Verify functionality, monitoring, and dependent services.
- Record the outcome and close the approved change record.
